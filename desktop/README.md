# P-Ⅲ型频率曲线适线分析软件（水文频率计算）

一款面向水文学专业的 Windows 软件：输入多年水文资料，自动计算统计参数，
在海森机率格纸上绘制皮尔逊Ⅲ型（Pearson Type III）频率曲线，支持人工/自动适线，
输出设计成果表与报告。**完全离线运行，数据仅保存在本机。**

## 快速开始

1. 双击运行 `P3频率计算软件.exe`（单文件绿色软件，无需安装）；
2. 首次启动约需 5~15 秒（单文件程序自解压，属正常现象）；
3. 在左侧文本框中输入数据（每行一个年值，或“年份 数值”两列），
   也可点击【打开文件…】导入 txt/csv/xlsx 文件；
4. 软件自动用**矩法**估计均值、变差系数 Cv、偏态系数 Cs，并绘制：
   - 经验点（P = m/(n+1) × 100%，数学期望公式）
   - P-Ⅲ 理论频率曲线（红色）
5. 适线（两种方式）：
   - **人工适线**：拖动 Cv、Cs 滑杆（或输入精确值），曲线实时更新；
   - **优化适线**：点击【优化适线（最小二乘）】自动求最优参数；
   - 勾选“均值固定为样本均值”时仅调节 Cv、Cs（经典适线法，推荐）。
6. 左侧成果表给出各设计频率（0.01% ~ 99.9%）对应的重现期、
   离均系数 Φ 与设计值；可导出图片（PNG/SVG/PDF）、CSV 成果表、
   计算成果报告（TXT），并支持工程保存/载入（json）。

快捷键：`F5` 重新计算，`Ctrl+O` 打开数据文件，`Ctrl+S` 保存工程。

## 软件截图说明

主界面分为四个功能区：
① 数据输入  ② 样本统计量  ③ 频率曲线参数调节  ④ 设计成果表；

## 计算方法

### 皮尔逊Ⅲ型分布

密度函数

    f(x) = β^α / Γ(α) · (x - a₀)^(α-1) · e^(-β(x-a₀))

以均值 x̄、变差系数 Cv、偏态系数 Cs 表达：

    α = 4/Cs²，β = 2/(x̄·Cv·Cs)，a₀ = x̄(1 - 2Cv/Cs)

标准化离均系数 Φ = (x - x̄)/(x̄·Cv) 满足

    P(X > x_p) = Q(α, t)，t = 2Φ/Cs + 4/Cs²

其中 Q 为上不完全伽马函数。给定频率 P 与 Cs，先由 Q⁻¹ 反解 t，再得
Φ = Cs(t - α)/2，最后 x_p = x̄(1 + Cv·Φ)。
当 Cs = 0 时退化为正态分布（Φ = -Φ⁻¹(P)）。

> 注：不完全伽马函数及其逆由软件内置数值算法实现（连分式 + 级数 +
> 牛顿/二分法），与 SciPy 交叉验证精度达 1e-13 量级，不依赖外部计算库。

### 经验频率（数学期望公式 / Weibull）

    P_m = m/(n+1) × 100%，m = 1, 2, …, n（按年值从大到小排序）

### 矩法初值

    x̄ = Σx/n
    Cv = sqrt(Σ(Ki-1)²/n)，Ki = xi/x̄
    Cs = Σ(Ki-1)³/(n·Cv³)

矩法结果仅作初值，最终参数以适线为准（水文规范常用做法）。

### 优化适线

对给定 Cs，以权重 w = 1/x² 作加权最小二乘解出最优均值与 Cv，
目标函数为相对残差平方和 Σ[(x - x̂)/x]²；在 Cs ∈ [-1, 8] 上三级网格
搜索全局最优（均值可固定为样本均值）。

## 注意事项

- 数据建议为单站多年连续序列，n ≥ 20 时适线结果较稳定；
- 年最大洪峰流量/年降水量/年径流量等正偏序列一般取 Cs = (1~4)·Cv；
- 负偏（枯水分析）可手动将 Cs 调为负值；
- 若导入旧版 `.xls` 文件提示缺少组件，请将文件另存为 `.xlsx` 格式。
